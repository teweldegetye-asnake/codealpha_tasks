UNIVERSITY EMERGENCY ALERT SYSTEM

A mobile and web based system that allows students and university community to quickly report emergencies with thier location to adminstrators.   • HTML
  • CSS
  • JavaScript
  • Firebase
  • Cordova

Main Features:

  • GPS location

  • Alert management
